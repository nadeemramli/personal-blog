# Visualization Concept — Part 4.1: Progressive Summarisation

## 1. The Big Idea

**One sentence:** A note you have to re-read in full has saved you nothing — so this poster shows a noisy raw capture being *conditioned* down to a single sharp signal that then feeds one living map node which grows **sharper, not longer**, every time you learn more.

The reader should feel the difference between two failure-and-success states at a glance: the hoarder's path (highlight everything, save it, re-read the whole wall later — infinite cost, no gain) versus the operator's path (strip the signal stage by stage, metabolise it into the map, and let *use* decide what's worth keeping). The emotional takeaway is relief and precision: *I don't have to keep more, I have to keep less, better.*

## 2. Visual Metaphor or Structure

**The visual anchor is a signal-conditioning bench** — a horizontal signal-processing / filter-chain schematic, the kind you'd see for an audio mastering chain or a DSP noise-reduction rack, rendered in the pillar's electronics language. A raw, wide, noisy waveform enters on the left; it passes through four conditioning stages that each strip lower-value material and raise signal-to-noise; the clean output is **not a smaller pile of notes** but a single **map node** that densifies in place.

Why this metaphor fits the argument:

- Progressive Summarisation literally *is* signal conditioning: capture (raw signal) → bold (first attenuation) → highlight (second) → one line (the recovered signal). Layers of emphasis = stages of a filter chain.
- The article's hardest reframe — *your map is the summary, and "progressive" means progressive map-refinement* — is captured by making the chain's output a node whose **internal resolution rises while its footprint stays fixed**. You can draw "sharper, not longer" directly.
- The **use-gate discipline** ("you only add a layer when you're already in the note for a real reason") becomes a normally-open gate on each stage that closes only on a real reopen — so un-reopened notes correctly stay at RAW, and that's calm, not a fault.
- The feedback **loop** (`Encounter · Integrate · Link · Prune`) is a return arc that re-injects new material into the *same* node — the same "write the improvement back into the durable artifact" shape as Part 3.1.

**Distinctness (critical — this track reuses one locked style, so each poster must be a different instrument):**

- 1.0 = vertical series boot-stack · 1.1 = L→R threat-intercept trace · 2.0 = enclosure cross-section · 3.0 = clockwise closed-loop ring · 3.1 = RAM↔DISK write-back latch · 4.0 PARA = heat-graded storage bus.
- **4.0 vs 4.1:** 4.0 answered *where to put many notes* (a bus sorting many packets by heat). 4.1 answers *how to make one note worth keeping* (a chain compressing one signal into the map). Many-notes bus → single-signal chain. They are deliberately complementary halves of the Knowledge layer.
- **vs the Cognitive 1.1 "tuning bench":** that bench was a *dose-response* instrument (gas/brake knobs, an inverted-U transfer curve). This is a *compression / filtering* instrument (a multi-stage attenuator chain feeding a densifying node + twin resolution/length meters). Same pillar vocabulary, different machine. Do **not** redraw an inverted-U curve here.

## 7. What to Avoid

- **The sales-funnel cone.** Do not render compression as a big funnel narrowing to a drop. It's a *signal/filter chain with rising signal-to-noise*, not a funnel — the funnel reads as marketing and loses the "conditioning" meaning.
- **Skeuomorphic yellow-highlighter-on-paper.** A literal page covered in yellow marker is the obvious cliché *and* it visually celebrates highlighting, which the article attacks. Highlighting here is a filter *stage* in schematic form, not a marker.
- **A growing/bigger output box or stack.** The map node must keep a **fixed footprint** while its internal lattice densifies. If the node gets visibly *bigger* as it improves, the poster contradicts its own headline ("sharper, not longer").
- **The glowing-brain / lightbulb / "second brain" / gears icon kit.** Banned across the pillar.
- **Re-drawing a sibling instrument.** No clockwise process ring (that's 3.0), no RAM↔DISK floppy/disk latch (3.1), no inverted-U dose-response curve (Cognitive 1.1), no heat-graded bus of many packets (4.0). This is a single-signal conditioning chain + densifying node.
- **Red-flooding.** Exactly one red object (the all-highlight re-read loop). Un-reopened raw notes are grey and *calm*, not red — leaving notes unsummarised is correct behaviour, not an error.
- **An equal-weight 4-pastel-arrow SmartArt** for `Encounter · Integrate · Link · Prune`. It's a feedback arc into the node, not a generic process strip.
