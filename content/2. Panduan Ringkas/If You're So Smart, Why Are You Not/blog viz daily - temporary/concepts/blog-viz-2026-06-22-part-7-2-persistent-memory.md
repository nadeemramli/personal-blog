## 2. Visual Metaphor or Structure

**The visual anchor: a DUAL-PORT NON-VOLATILE MEMORY CORE — one shared store, two readers, wired into a closed loop.**

In electronics a *dual-port memory* is a single memory bank that two processors both read and write through two independent ports. That is the precise, literal rendering of the article's thesis ("you and your agent end up sharing one brain, made of plain text, that you can both read"). The metaphor fits because the article's whole argument is a **collapse of two things into one** — so the instrument must be a single core with **two ports**, not two stores with a cable between them.

Layered onto the core, four ideas from the article render as physical features of the same object:

- **"The answer is plain text" →** the core's substrate is etched **Markdown** itself: faint `#`, `-`, `[[ ]]` glyphs are the *conductor material*. Everything is built on `.md`.
- **"One fact per file" →** the core is a **lattice of small, individually-labelled CELLS**, each a single memory tile (a preference · a project's state · a decision + why · a reference), colour-typed by the four memory types.
- **"Bidirectional links → a graph the model can traverse" →** cells are joined by **two-way LINK traces** (arrowheads on *both* ends), and a traversal pulse shows the agent following links from one project cell out to its people / decisions / history — "assemble context on demand."
- **"A light index file" →** a thin **INDEX RAIL** taps the top edge of the core, one address-line per cell — the table of contents every run loads first "to know what it knows."

And the macro-composition does the finale's structural job: **the seven-layer stack is bent into a closed RING around the core, not stacked into a ladder.** The top of the loop (AI as a Worker — the agent) writes back *down* into the **same** Knowledge-System node at the bottom that the human reads from. The weld where the agent's write-port meets the human's knowledge node **is the shared core at the centre**. That single weld is the literal picture of "this is why the stack is a loop and not a ladder."

**Composition family = HUB-AND-RIM / concentric — deliberately new for the set.** Every prior Productive instrument was linear (1.0 vertical series boot-stack · 1.1 L→R threat trace · 2.0 enclosure section · 3.0 clockwise ring · 3.1 RAM↔DISK latch · 4.0 heat-bus · 4.1 distillation bench · 4.2 note-to-tool pipeline · 5.0 command-bus rack · 6.0 capacity manifold · 7.0 transduction chain · 7.1 detachment bench). A **radial core-with-ports inside a closing ring** is the one composition that says "everything returns to the centre" — the finale earns the only concentric layout in the pillar.

## 8. What to Avoid

1. **Two brains merging into a glowing AI super-brain / a brain-shaped neural-net sphere / lightbulb / synapse-sparkle kit.** The style rule is explicit: memory is a routing-and-storage system of **plain-text cells and links**, *never a glowing organ.* Convergence is shown by **two ports into one core**, not two glowing hemispheres fusing.
2. **Redrawing 3.1's RAM↔DISK write-back latch.** This is the single biggest trap — 7.2 and 3.1 are both "memory across runs." Keep them distinct: 3.1 is a **one-directional correction-latch** (chat → file, corrections *decay* run-over-run, the hero is the SAVE step). 7.2 is a **bidirectional dual-port SHARED store with two masters**, and the hero is **convergence/sameness** (one store, two ports, the loop closing) — *not* the save step. Do **not** make a top volatile RAM rail the hero, do **not** reuse the "corrections decay" twin-trace meter; the session-wipe buffer here is a small subordinate detail feeding the core.
3. **The stock "AI memory" cliché icons** — a database cylinder, a stack of floppy disks, or a 3D vector-store dot-cloud. The store must read as a **graph of labelled plain-text cells with an index rail**, because the article's whole point is that robust memory is *plain Markdown*, not a vector DB.
4. **A rising LADDER / staircase of the seven layers.** The article says loop **not** ladder; 1.0 already owns the vertical series boot-stack and 7.1 the horizontal bench. The seven layers here must be a **closed ring welded back into the core**, or the poster silently contradicts the thesis and repeats a sibling.
5. **Red-flooding / calm-as-alarm.** Only the append-only duplication/contradiction rot is red. The session-wipe is *normal* (grey, not red); the ghosted "separate agent memory" is a *corrected instinct* (grey, struck-through), not a fault. The running shared loop must feel resolved.
6. **An android-at-a-desk / chat-bubble cartoon for the agent.** The agent is the plain miniaturised pipeline module from 7.0/7.1 — a worker-unit on a port, not a creature.
