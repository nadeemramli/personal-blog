> [!abstract] **Read this before running any stock / forecast / catalog / ordering work.** Six standing checks that keep the OS trustworthy. The forecast is only as good as these. Pair with [[Stock Forecast — Intake Protocol]] (the question script) and [[Stock Reconciliation Policy]] (PO→stock).

## The six checks

### 1. Purchase Orders → update stock
Sweep `4. Management/Purchase Orders/` for any buy newer than each product's `stock_as_of`; post its `→ Stock` delta to `stock_on_hand` and bump `stock_as_of`. **A purchase isn't done until stock reflects it.** Net in-flight (cart / almost-paid / on-the-way) buys too. See [[Stock Reconciliation Policy]].

### 2. Date & protocols → predict depletion (and ask)
Use today's date + each item's dosing schedule / protocol to project run-out (`days_until_empty = stock_on_hand ÷ effective_daily`). Stock decays silently, so **periodically ask Nadeem to eyeball real stock** ("how's stock looking on X?") rather than trusting the model blindly — reconcile his count back into the notes.

### 3. Catalog product-detail consistency (vs the PO)
Before trusting a number, confirm the product note's spec matches what was actually bought. **A buy can change the spec** — e.g. moving Yohimbine 5mg → 10mg, or a bigger pack — which changes `base_dose` / `package_size` / `cost_per_bottle` / `cost_per_mg`. If a PO's item differs from the note, update the note (or split into a new note) so dose-math stays correct.

### 4. Stock ↔ Wishlist dedup
Check `2. Catalog/Products/Stock/` vs `Products/Wishlist/`: nothing in Wishlist should be something already owned in Stock, and vice versa. When a Wishlist offer is bought, **move it to Stock** (keep `product_id`). Flag bought-but-not-catalogued into [[0. Reconciliation — Gaps]].

### 5. Sources → context for ordering
Keep `2. Catalog/Sources/` current: **shipping time, trust level, shipping fees, contact email / method, payment method (crypto vs card), warehouse**. These set lead time — order slow/overseas vendors (kohohpharma crypto, INDEXA/TCI, Beligas Intl) first. Landed cost ≠ sticker.

### 6. Schema / Uses → protocol, dose, frequency, rhythm
Read `3. Schema/` (dosing schedules) and `1. Uses/` (protocols, cycles) for correct dose / frequency / cycle-weeks before forecasting. Always factor [[Training Rhythm]] (3-on-1-off, ~5.25 training days/wk — **constant across all cycles**) and the [[Pinning Schedule]] (pins/week per cycle) for training-day items and consumables.

## When to run
- Any "are we good stock-wise / what to buy / forecast" request → run all six, then [[Stock Forecast — Intake Protocol]].
- After logging new POs → run checks 1, 3, 4.
- Before placing an order → run checks 5, 6 (lead time + correct qty).
