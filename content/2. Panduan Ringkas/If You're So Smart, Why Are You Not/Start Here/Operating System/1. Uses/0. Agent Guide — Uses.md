## Cycle-length classes (`length_class` on every cycle note)

| Class | Weeks | Meaning |
|---|---|---|
| `short` | 8 | Short cycle |
| `medium` | 12 | Standard cut / lean-bulk block |
| `long` | 16 | **Maximum** normal cycle |
| `eq` | 20 | **Equipoise exception** — Boldenone Undecanoate needs **≥12wk minimum** (slow undecanoate ester), so EQ blasts run 20wk (see [[2027 Q1 — Blast 1]], [[2028 Q1 — Blast 2]]) |
| `short-extended` | irregular | A run stretched for logistics (e.g. Q2 2026 extended to burn down Test C) |

`length_class` ≠ `current_phase`: the phase field is **in-cycle progression** (early/medium/high/highest). Don't conflate them.

## Agent rules for this folder

1. **Forecasting an item? Resolve its context here first**: which cycle (`items` list), which protocol owns it, on-cycle vs year-round (`Year-Round Shield` items never stop; `On-cycle only` items burn `weekly-mg × weeks_per_year`).
2. **Training-day math:** anything dosed TD/ITD or consumable-per-pin uses [[Training Rhythm]] (≈5.25 d/wk) and [[Pinning Schedule]] — not the raw schedule factor.
3. **Respect the design rules:** dose changes must comply with [[Endocrine Design Rules]] and are **provisional until bloodwork confirms** ([[Bloodwork & Calculated Biomarkers]] gates).
4. **Don't duplicate dose data.** Doses for computation live on product notes (`daily_dose`, `dosing`); protocols describe use. If a protocol and product note disagree, flag it — don't silently pick one.
5. **Theory vs execution split:** `(Theory)` notes explain mechanisms; `Deployment Protocol` / `Daily Schedule` notes are executable. Quote executable notes when telling Nadeem what to do.
6. PED calendar changes (new cycle, dose change, compound swap) ripple into stock forecasts → re-run [[Stock Forecast — Intake Protocol]] afterwards.
