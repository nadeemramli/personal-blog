# Diet Micronutrient Coverage

> [!abstract] Placeholder for recipe-driven micronutrient coverage.
> Supplements cover many items, but the diet should own most sodium, potassium, calcium, iodine, vitamin A, vitamin E, fiber, and phytonutrients.

## Primary Open Items

| Nutrient | Current status | Likely source path |
|---|---|---|
| Vitamin A | Not explicitly covered by the current stock stack | Eggs, liver, dairy, orange vegetables, dark leafy greens, or a no-iron multivitamin if diet is inconsistent. |
| Vitamin E | Not explicitly covered by the current stock stack | Nuts, seeds, olive oil, avocado, wheat germ, or mixed tocopherol/tocotrienol product. |
| Iodine | Depends on salt/seafood/dairy pattern | Use iodized salt intentionally unless diet proves enough. |
| Potassium | Food-first; not pill-first | Potatoes, legumes, yogurt/milk, fruit, vegetables, meat/fish. |
| Calcium | Food-first | Dairy, fortified soy/milk, canned fish with bones, calcium-set tofu, greens. |
| Chromium / manganese / trace minerals | Unknown until recipes are logged | Usually diet or no-iron multivitamin. |

## Decision Rule

If recipes reliably cover a nutrient, do not add a supplement. If recipes are unstable or the nutrient is repeatedly missed, route to either [[Year-Round Shield]] or [[Electrolyte Protocol]] as a tracked support item.
