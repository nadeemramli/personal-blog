# Bulk Protocol

**Goal:** gain mass on a caloric surplus, partitioning as much as possible toward muscle.

## The stack
- **Food goes up** — establish the surplus first; the chemistry only works on top of calories.
- [[MK-677]] — appetite + GH/IGF support.
- [[Retatrutide]] — **low dose**, for nutrient partitioning and appetite control on a surplus.
- [[Oxandrolone (Anavar)]] — **4 on training days, 2 on rest days** (split morning/evening).
- [[Proviron]] — run if test is dosed high (twice weekly). **Remove Proviron if EQ ([[Boldenone Undecanoate|Equipoise]]) is in the cycle.**

## Always-on (every phase)
- [[GHK-Cu]]
- [[KPV]]
