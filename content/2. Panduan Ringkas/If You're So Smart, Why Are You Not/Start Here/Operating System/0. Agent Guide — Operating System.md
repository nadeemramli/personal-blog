## What this OS is

The Operating System makes Nadeem's orderliness bill (money + time) **honest and computable**. Everything serves one equation:

`Monthly Nut = Living (E) + Protocol & Foundational (F) + Executional (X)` → `Surplus = Income − Nut` → freedom numbers.

Obsidian (markdown + Bases) is the **system of record**. All data lives in note **frontmatter**; Bases are just views. Retool/Postgres is parked.

## Global conventions (apply everywhere)

1. **Frontmatter is the database.** Bases filter on `type` + fields. Never store state in prose only; never store fast-changing state in folder location — `status` is a field.
2. **`0. ` prefix = meta file** (a Base or a guide/index), pinned conceptually at the top of its folder. Bases live *inside* their folders, never on the OS root.
3. **Wikilinks are foreign keys.** Products link protocols (`protocols`), sources (`source`), dosing codes (`dosing`); cycles link products (`items`). Keep them resolving when renaming — old names go in `aliases`.
4. **Idempotency.** One physical product = one note = `Compound (spec) — vendor` = one `product_id`. Check before creating; UPDATE, never duplicate.
5. **Peptides are out of the personal bill** — funded by INDEXA side-business. Exclude from Nut roll-ups (`restock: — (INDEXA)`).
6. **Guard every roll-up** with `count_in_total = true` and `status = active`.
7. **Training rhythm is a constant:** 3-on-1-off ≈ **5.25 training days/wk**, across all cycles ([[Training Rhythm]]).
8. **Ask, don't assume.** Stock decays silently and the catalog has known gaps — when forecasting, run the intake questions and ask Nadeem to eyeball physical stock periodically.
9. **Known data quirks (still being fixed):** `stock_on_hand` units inconsistent across notes; `cost_per_dose = cost_per_bottle / package_size` is a unit mismatch (gives cost per tab/ml, not per mg dosed). See [[Skeleton — Build Map]] §3.1 before trusting any cost number.

## The communication loop

When the agent needs data only Nadeem has (a physical count, a price check, a decision), it **creates/updates a file in `4. Management/_Ledger/`** stating exactly what's needed. Nadeem fills it; the agent consumes it and moves forward. Never block silently — leave a ledger trail.
