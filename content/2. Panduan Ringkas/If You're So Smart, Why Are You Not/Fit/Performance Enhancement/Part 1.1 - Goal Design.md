## Why the goal comes first

A useful physique goal has two parts. The first describes the outcome you want, such as a stronger squat or a smaller waist. The second describes the performance and habits you want to keep while pursuing it. A goal that depends on sacrificing everything else is hard to evaluate honestly.

## Turn the goal into a program

Choose one main outcome and one or two checks on the trade-off. If waist size is the main outcome, track a familiar lift and how well you recover between sessions. If strength is the main outcome, track a repeatable set and watch whether body-weight changes fit the original goal. Use the same measurement conditions each time.

Set a review date and name the evidence that would make you change the plan. Start with training, food, and recovery. For readers weighing enhancement, use the [documented health risks](https://pmc.ncbi.nlm.nih.gov/articles/PMC4026349/) to inform the decision separately from the physique goal.
